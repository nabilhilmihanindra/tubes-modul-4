# Sahabat Warga – Modul IV Soal 2

Implementasi terarah materi Form/Input, Tombol/Interaksi, dan Chart untuk proyek
Sistem Informasi Pelaporan Kriminalitas Kota Palembang.

## Menjalankan
`flutter pub get` lalu `flutter run`.

Data contoh disimpan sementara di memori melalui Provider. Aplikasi ini merupakan
prototipe pembelajaran untuk modul Modul IV, bukan backend produksi.
